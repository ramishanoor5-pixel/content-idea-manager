# Content Idea Manager

## About the Project

The Content Idea Manager is a simple and interactive web application built using HTML, CSS, and JavaScript. It helps users organize their content ideas, categorize them by type, track their progress, and manage them in one place.

This project is part of my JavaScript Intermediate internship Task 4, where I am practicing DOM manipulation, event handling, and local data storage.

## Features

* **Add Ideas:** Create new content ideas.
* **Edit Ideas:** Update existing ideas whenever needed.
* **Delete Ideas:** Remove ideas that are no longer relevant.
* **Categorize Content:** Organize ideas by type, such as Video, Blog, or Post.
* **Manage Status:** Mark ideas as Draft, Published, or Archived.
* **Filter Ideas:** Filter content by type or status.
* **Data Persistence:** Store ideas in localStorage so they remain available after refreshing the page.
* **Dynamic Interface:** Update the displayed ideas whenever content changes.

## Technologies Used

* JavaScript (Vanilla JavaScript)
